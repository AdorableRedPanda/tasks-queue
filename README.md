# tasks-queue

Динамическая очередь асинхронных задач.

Создать очередь задач, где:
1. Задачи выполняются последовательно
2. Каждая задача может быть асинхронной
3. Задачи могут добавлять новые задачи в очередь во время выполнения
4. Поддерживается таймаут выполнения 
5. Задачи должны логироваться


Требования к коду:
 * задачи должны быть независимыми
 * задачи должны быть тестируемыми
 * добавление новых задач и типов задач должно быть простым
